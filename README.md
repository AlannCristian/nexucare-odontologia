# NexuCare Odontologia

Landing page de uma clínica odontológica fictícia, criada para estudo
e portfólio com Next.js, React, TypeScript e Tailwind CSS.

## Como rodar

- `npm ci` instala as dependências.
- `npm run dev` inicia o ambiente de desenvolvimento.
- `npm run build` gera a versão estática na pasta `out/`.
